N-Island — Dynamic Island for Windows / Dynamic Island для Windows
made in TG @Ne1zvestny1i & Claude

RU
1. Распакуй архив в любую папку (например, Документы\N-Island).
2. Запусти NIsland.exe. Устанавливать ничего не нужно.
3. Если Windows покажет «Windows защитила ваш компьютер» — нажми «Подробнее» → «Выполнить в любом случае»
   (программа без платной цифровой подписи, исходный код открыт на GitHub).
Чёлка появится сверху экрана. Наведи курсор — она раскроется. Правый клик — настройки.
Ctrl+Alt+L — Центр управления ноутбуком. Язык меняется в «Настройки → Язык».

EN
1. Unzip anywhere (for example Documents\N-Island).
2. Run NIsland.exe. Nothing to install.
3. If SmartScreen says "Windows protected your PC" — click "More info" → "Run anyway"
   (the app is not code-signed; the source code is open on GitHub).
The island appears at the top of the screen. Hover to expand, right-click for settings.
Ctrl+Alt+L opens the Laptop Control Center. Change the language in Settings → Language.

Equalizer APO (GPL-2.0) is embedded as its official installer and runs only when you press Install — see THIRD-PARTY-NOTICES.txt.
