# История версий / Changelog

## 1.5.0 — первый публичный релиз
- **Языки интерфейса**: русский, English, українська — встроены, работают без интернета.
- **Оптимизация Windows и программ**: 20 настоящих параметров (лёгкий интерфейс, запись Game Bar, ускорение мыши, сеть для игр, планирование GPU,
  фоновые приложения, виджеты, Edge/Chrome в фоне, SysMain, индексирование, гибернация, быстрый запуск, раздача обновлений, автозапуск флешек),
  профили «Слабый ноутбук / Игры / Батарея», тонкая настройка программ (видеокарта, приоритет процессора, совместимость). Всё с откатом.
- **Журнал активности**: камера, микрофон и место — кто, когда и сколько; разрешения сайтов в браузерах (Chrome, Edge, Яндекс, Brave, Vivaldi, Opera, Firefox);
  какие программы и когда запускались; кто присылал уведомления; что устанавливалось; какие флешки подключались.
- **ИИ-объяснения** ✨ у каждого пункта центра: что это, кому включать, риски, как вернуть.
- **Звуки**: свой синтезатор — стекло, перезвон, маримба, мягкий, колокол, цифровой, будильник; выбор для таймера, напоминаний, уведомлений и важного; громкость.
- **AMOLED**: чисто чёрный стиль чёлки и тема окон.
- **Лёгкий режим** для слабых ПК (включается сам на 4 ГБ памяти / 2 потоках / без видеоускорения), безопасный запуск служб, сборки x64, x86 и lite.
- Нормальные кнопки (раньше на широких кнопках WPF рисовал сплюснутый эллипс), новое окно «О программе» с проверкой обновлений.

## 1.4.0 — Центр управления ноутбуком
- Отдельное окно (Ctrl+Alt+L): индекс здоровья, глубокая очистка со строгой проверкой, защита от слежки с резервной копией,
  скорость, питание и батарея, файлы и дубликаты, интернет и DNS, советник автозагрузки, 14 исправлений, паспорт ноутбука, автоматизация.
- Тексты песен: запасной источник NetEase, сдвиг для каждой песни, караоке, перевод строк, кэш; полоска прогресса в чёлке.
- Исправлены: строка Wi-Fi, даты на украинском, стирание истории ИИ-чата, двойные запросы текстов.

## 1.3.0
- ИИ-чат в чёлке (Claude, OpenAI, Gemini, Groq, DeepSeek, свои провайдеры, бесплатный без ключа), обслуживание ноутбука, 30+ инструментов по API,
