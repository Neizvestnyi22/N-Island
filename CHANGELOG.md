# История версий / Changelog

## 1.8.0 — живой остров, MCP для агентов, свой Защитник, пульт ПК в Telegram 2.0
- **Живой остров.** В свёрнутой чёлке живёт персонаж (капля, кот, привидение, робот, зайчик): танцует под музыку, думает, пока отвечает ИИ, слушает во время звонка, спит ночью и в «Не беспокоить», радуется наведению, грустит при низком заряде.
  Жидкое стекло стало настоящим: фон под стеклом чётче и ярче, края преломляют его как линза, блик следует за курсором, ободок светится в такт музыке, по острову пробегает свет при уведомлении.
- **47 визуализаторов** (было 13): 34 новых в двух группах — «Ностальгия» (огонь, звёзды, плазма, VU-метры, Лиссажу, светомузыка, «Матрица», ЭЛТ, пиксели, кассета, винил, ночной город…) и «Современные» (сфера, галактика, сияние, горные гряды, ретровейв, ДНК, молнии, лава, калейдоскоп, фонтан, кардиограмма, цветок, соты…).
  12 новых палитр, свои цвета, избранное ★ (автосмена и стрелки ходят по нему), тонкая настройка: чувствительность, плавность, след, плотность, скорость, свечение, зеркало, вспышка на ударе, сканлайны, фон, FPS.
- **Тексты песен:** 5 стилей (Apple, классика, неон, минимал, прыжок), шрифт, цвет, выравнивание, строка латиницей под текстом (кириллица, греческий, корейский), копирование и сохранение .lrc,
  **текст на рабочем столе** — строка поверх всех окон с караоке-заливкой (можно закрепить, чтобы клики проходили насквозь; прячется в играх и фильмах). Поиск стабильнее: источник, который сбоит, временно пропускается, на 429 — повтор, сильное совпадение NetEase/Kugou не ждёт LRCLIB.
- **Telegram-бот — пульт ПК 2.0.** Меню кнопками: музыка, эквалайзер, звук и выходы, громкость программ, экран (яркость, снимки, выключение монитора, тема, обои), окна (свернуть, развернуть, закрыть), клавиатура и мышь, презентации, файлы (папки, поиск, скачать, zip, в корзину, печать присланного), камера, где ноутбук, питание, сеть, VPN, режимы, задачи, таймер, напоминания.
  **ИИ острова прямо в боте** (`/ai` или просто текст) — общий диалог с чатом в чёлке, ответ появляется по мере набора. Новое из Bot API: реакции, кнопки «скопировать», сворачиваемые цитаты, описание бота. Опасные разрешения меняются только на ПК.
- **ИИ:** новые провайдеры (LLM7 без ключа, Cerebras, Perplexity, GitHub Models, Hugging Face, Zhipu GLM, Qwen и др.), список моделей с сервера с обновлением раз в 3 дня и поиском, запасной провайдер, если основной не ответил, автоподбор модели, если провайдер её убрал,
  свои провайдеры с заголовками (Azure `api-key`), исправлены адреса с `/chat/completions`, повтор без `max_tokens`/`temperature`/`stream` для строгих серверов, скрытие блоков `<think>`, «Проверить все».
- **ИИ-агенты на ПК** (Claude Code, Codex, Gemini CLI, Qwen Code, OpenCode, Copilot CLI, Aider, Cursor Agent): кто установлен и кто работает, запуск в папке проекта или задание без окна, уведомления «агент ждёт подтверждения / закончил» в острове и в Telegram (хуки Claude Code и notify Codex), расход токенов Claude Code за день, `/agents` и `/agent` в боте.
- **MCP-сервер для агентов:** около 30 инструментов — состояние ПК и острова, что играет, текст песни, уведомления, заметки, задачи, напоминания, таймер, буфер, снимок экрана, всплывашка и полоса прогресса в острове, сообщение в Telegram, смена вида острова, проверка безопасности и файла на вирусы.
  Три уровня доступа (чтение, управление, настройка острова), только с этого ПК и по токену; подключение к Claude Code одной кнопкой, конфиги для Claude Desktop, Cursor и Codex.
- **Защитник N-Island** — дополняет Защитник Windows: база известных угроз (signature-base), движок Windows (AMSI), подпись, эвристики программ (упаковщики, энтропия, опасные сочетания функций) и скриптов (скрытый запуск, скачивание и выполнение, отключение Защитника, удаление теневых копий),
  быстрая проверка, проверка папки и файла, онлайн-проверка по отпечатку (CIRCL), карантин с шифрованием, защита в реальном времени для «Загрузок», рабочего стола и автозагрузки, слежение за автозапуском, проверка безопасности Windows.
- **Здоровье ПК:** оценка из 100, сбои и синие экраны за месяц, устройства с ошибками, обновления программ через winget, частота процессора и троттлинг, турбо-режим (возвращается одной кнопкой), что занимает диск, файлы больше 100 МБ, дубликаты, проверка памяти, TRIM.
- **Wi-Fi:** раздача интернета с ноутбука, стабильность связи (джиттер, потери, всплески), самый быстрый DNS, трассировка, быстрый ремонт интернета, всё о подключении, разбудить ПК по сети, карта сигнала по комнатам, безопасность сетей вокруг («злые двойники», WPS, открытые сети), задержка до регионов мира, генератор надёжного пароля.
- **Погода:** точка росы, видимость, облачность, пыльца, фаза луны, радар, завтра теплее/холоднее, другие города одним кликом, предупреждения об опасной погоде (гроза, шторм, заморозок, жара, УФ) на экран и телефон. Поиск города точнее (Миколаїв больше не путается с сёлами).
- **Интеграции (41 + свои):** новые — бесплатные игры, скидки на игры, землетрясения, магнитные бури и сияние, фото дня NASA, новые версии с GitHub, «Этот день в истории». **Свои интеграции** без программирования: любой JSON API, число с порогами, изменение страницы сайта, «сайт работает?».
  Убраны Монобанк и воздушная тревога.
- **Исправлено:** персонаж хмурился вместо улыбки; поиск агентов не видел Claude Code из приложения Claude; размер AppData считался с облачными файлами (525 ГБ); сбои Windows не читались из-за кодировки; Николаев находился как село; ИИ-провайдеры с «/v1/» в конце адреса; в украинском переводе «AI» вместо «ШІ» и «челка».

## 1.7.0 — эквалайзер, визуализаторы, 36 интеграций, пульт ПК в Telegram
- **Эквалайзер для всего звука Windows.** Кривая на 10 полос перетаскивается мышью поверх живого спектра, 17 пресетов, свой профиль для наушников, колонок и Bluetooth (включается сам при переключении).
  Работает через бесплатный движок Equalizer APO — его можно установить из N-Island одной кнопкой. Свои настройки APO не трогаются, всё отключается кнопкой.
- **Визуализаторы под музыку — 13 стилей.** Классика старых плееров («Полосы и волна», осциллограф, светодиоды, «Амбиент», «Алхимия») и новые (круговой спектр, тоннель, частицы, спектрограмма, неон, «Капля», зеркало).
  В плеере — колонкой справа со строкой песни поверх; в отдельном окне — на весь экран (F11), стили стрелками, автосмена, текст песни крупно. Слушает настоящий звук (удары и темп определяются сами), только пока на экране.
- **Полоски в свёрнутой чёлке** пляшут под настоящий звук: бас, середина, верха.
- **Синхронизация текста.** Строка загорается точно в момент, а не с шагом 0,2 с. Сдвиг запоминается и для приложения (Chrome, Spotify): новые песни идут сразу с поправкой.
  У приложений без времени трека (Firefox) начало песни ловится по звуку. Поиск текста быстрее: NetEase и Kugou спрашиваются параллельно с LRCLIB.
- **Плеер:** таймер сна (15/30/60 минут или после этого трека), кнопки эквалайзера и визуализатора.
- **Telegram-бот — пульт ПК.** Кнопки музыки и громкости, `/panel`, `/status`, `/top` (что грузит ПК), `/disk`, `/battery`, `/wifi`, `/ip`, яркость, режимы, эквалайзер, «не засыпать»,
  заметки, задачи, напоминания, таймер, буфер обмена, `/find` (громкий сигнал), погода, тревога, посылки. По отдельным разрешениям (выключены по умолчанию): программы (`/apps`, `/kill`, `/open`),
  файлы (`/ls`, `/get`, присланный файл сохраняется на ПК), снимок экрана, блокировка/сон/гибернация/перезагрузка/выключение с подтверждением, команды Windows (`/cmd`, `/ps`). Ответ на команду — за секунду (длинный опрос).
- **Повітряна тривога** без ключа (siren.pp.ua): своя область, район или громада и места родных, «частково» по громадам, сколько длится и сколько было за сутки, артобстрел и другие угрозы,
  значок в чёлке, пауза музыки, сообщение об отбое. Если связи нет — честно «нет данных».
- **Нова пошта:** сумма к оплате, с какого дня хранение платное, «прибула!» со звуком, свои названия посылок, номер ТТН из буфера обмена — предложение отслеживать, полученные прячутся.
- **21 новая интеграция (всего 36):** почта по IMAP (Gmail, Outlook, ukr.net), Монобанк, Pushover, Pushbullet, Gotify, Slack, Matrix, Notion, Trello, Linear, Jira, GitLab, Toggl Track (вместе с помодоро),
  WakaTime, Twitch, Steam, Mastodon, Bluesky, Hacker News, Philips Hue, акции и индексы. Поиск по сервисам и группы. Новые события для пересылки: интернет пропал/появился, посылки, письма, деньги.

## 1.6.0 — VPN, интеграции, быстрый поиск
- **Время трека в любых приложениях.** Раньше у Firefox и части плееров (они не сообщают Windows время) не было ни времени, ни прогресса.
  Теперь N-Island считает прошедшее время сам, а длительность берёт из найденного текста или каталога (помечена «≈»).
  Позиция идёт по монотонным часам с учётом скорости воспроизведения; при смене трека время прошлого трека больше не подхватывается.
- **Плеер не «залипает» на закрытой вкладке.** Если в браузере закрыли вкладку и музыка заиграла в другой, остров переключается на новую сессию.
  После сна и перезапуска Проводника подключение к медиа восстанавливается само; кнопки управления сразу показывают результат и сверяются с приложением.
- **Тексты песен заметно лучше.** Точный запрос LRCLIB по длительности; новый запасной источник Kugou, помимо NetEase; простой текст через lyrics.ovh.
  Названия с YouTube, Spotify и VK чистятся: «Official Video», «Remastered 2011», «feat.», «Исполнитель - Название», «- Topic», «VEVO».
  Кандидаты сравниваются с учётом транслитерации («Земфира» и «Zemfira»), версия с другой длительностью показывается без синхронизации, а не вразнобой.
- **Синхронизация.** Подсветка по словам, если она есть у текста. Опережение строки настраивается. На проигрышах видны точки «● ● ●».
  Строки плавно растворяются у краёв, текущая чуть крупнее. Титры («Lyrics by», «作词») и заголовок убираются.
  Если LRCLIB недоступна, текст без синхронизации больше не запоминается навсегда.
- **VPN в острове.** Новая страница: включать и выключать Cloudflare WARP, NordVPN, Mullvad, Windscribe, Tailscale, PIA, конфиги OpenVPN, туннели WireGuard и VPN-подключения Windows.
  Остальные VPN показывают состояние. Внешний IP и страна, всплывашка при включении и выключении, замочек в острове.
- **15 интеграций** и страница «Сервисы»: Telegram-бот (события на телефон, сообщения боту — в остров), ntfy, Discord, вебхук, Home Assistant, Todoist,
  календарь iCal (Google, Outlook, iCloud) с напоминаниями, GitHub, RSS, ListenBrainz и Last.fm (скробблинг), курсы НБУ и крипта, Нова пошта, мониторинг сайтов,
  повітряна тривога (alerts.in.ua). Ключи шифруются (DPAPI), у каждого сервиса есть «Проверить» с понятной ошибкой.
- **Быстрый поиск (Ctrl+Alt+Space)** — окно в стиле Spotlight. Ищет программы и приложения Store (по первым буквам и в другой раскладке), параметры Windows, недавние файлы и буфер.
  Ещё умеет калькулятор, валюты и единицы, перевод, команды острова, поиск в интернете и ответ ИИ прямо в окне.
- **Wi-Fi.** Новая страница острова: сигнал вживую на графике, чтобы найти лучшее место в квартире; сети рядом; устройства в сети; проверка качества.
  В центре управления — полная проверка сети с советами: сигнал, 5 ГГц у роутера, загрузка канала, защита и WPS, стандарт роутера против адаптера,
  задержки и потери до роутера и интернета, скорость своего DNS против Cloudflare и Google, свежесть драйвера, лимитное подключение.
  Загрузка каналов 2,4 и 5 ГГц полосками, свободные каналы, тест скорости, переподключение, «забыть сеть», страница роутера, QR-код и хот-спот.
  Данные идут из Native Wifi API Windows и не зависят от языка системы.
- **OSINT и проверки.** Проверка ссылки на фишинг: раскрытие коротких ссылок, возраст домена, подмена букв, бренд в чужом адресе, история.
  Домен: WHOIS (RDAP), DNS и DMARC, сертификат, поддомены (Certificate Transparency), веб-архив, заголовки безопасности.
  IP: страна, провайдер, AS, хостинг или VPN. Утечка пароля через HIBP — пароль не уходит из компьютера.
  Фото: метаданные и GPS, чистая копия без них. Файл: SHA-256 и отчёт VirusTotal.
- **Без дублей.** Можно выключить баннеры уведомлений Windows (они остаются в центре уведомлений), окно «Автозапуск» и системное окно громкости.
  Всё обратимо и возвращается, когда N-Island закрыт.
- **Настройки.** Поиск работает на английском и украинском и подсвечивает найденный пункт. Значения обновляются, если поменять их из острова.
  Колесо мыши меняет числа. Появились резервная копия настроек (сохранить и загрузить) и сброс.
  Повреждённый файл настроек восстанавливается из резервной копии, а не начинается с нуля.
- **Стабильность острова.** Восстанавливается после сна, смены масштаба экрана, разблокировки и перезапуска Проводника. Показывает горячие клавиши, занятые другими программами.
- **Автообновление экранов** с живыми данными. Работает только пока экран открыт, запуски не накладываются, ошибка одного обновления не ломает остальные.
  Обновляются: VPN, «Сервисы», сети и устройства Wi-Fi, подключение Wi-Fi, программы с соединениями, память процессов, батарея, статусы интеграций.
- **Проверки ввода в OSINT:** ссылка, домен или IP с понятной подсказкой, если не похоже. Подключение PPPoE больше не принимается за VPN.
- **Светлый акцент** (белый, жёлтый): текст на акцентных кнопках, своих сообщениях в чате, «сегодня» в календаре и активном режиме стал тёмным — раньше он пропадал.

- **Языки интерфейса**: русский, English, українська — встроены, работают без интернета.
- **Оптимизация Windows и программ**: 20 настоящих параметров (лёгкий интерфейс, запись Game Bar, ускорение мыши, сеть для игр, планирование GPU,
  фоновые приложения, виджеты, Edge/Chrome в фоне, SysMain, индексирование, гибернация, быстрый запуск, раздача обновлений, автозапуск флешек),
  профили «Слабый ноутбук / Игры / Батарея», тонкая настройка программ (видеокарта, приоритет процессора, совместимость). Всё с откатом.
- **Журнал активности**: камера, микрофон и место — кто, когда и сколько; разрешения сайтов в браузерах (Chrome, Edge, Яндекс, Brave, Vivaldi, Opera, Firefox);
  какие программы и когда запускались; кто присылал уведомления; что устанавливалось; какие флешки подключались.
- **ИИ-объяснения** ✨ у каждого пункта центра: что это, кому включать, риски, как вернуть.
- **Звуки**: свой синтезатор — стекло, перезвон, маримба, мягкий, колокол, цифровой, будильник; выбор для таймера, напоминаний, уведомлений и важного; громкость.
- **AMOLED**: чисто чёрный стиль чёлки и тема окон.
- **Лёгкий режим** для слабых ПК (включается сам на 4 ГБ памяти / 2 потоках / без видеоускорения), безопасный запуск служб, сборки x64, x86 и lite.
- Нормальные кнопки (раньше на широких кнопках WPF рисовал сплюснутый эллипс), новое окно «О программе» с проверкой обновлений.
