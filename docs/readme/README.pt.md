Uma ilha no estilo iPhone no topo da tela: **música de qualquer app com letras sincronizadas, chamadas, notificações, timers e chat com IA** —
e uma **Central de controle do notebook**: limpeza profunda segura, proteção contra rastreamento, otimização fina do Windows, registro de atividade, energia, rede e reparos em um clique.
Cada opção tem selo de segurança, explicação simples e pode ser desfeita.

## ⬇️ Baixar
| Arquivo | Para quem |
|---|---|
| [**NIsland-win-x64.zip**](https://github.com/Neizvestnyi22/N-Island/releases/latest) | **Recomendado.** Windows 10/11 64 bits, tudo incluído. |
| [NIsland-win-x86.zip](https://github.com/Neizvestnyi22/N-Island/releases/latest) | PCs antigos com Windows 10 32 bits. |
| [NIsland-win-x64-lite.exe](https://github.com/Neizvestnyi22/N-Island/releases/latest) | Leve, requer [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0). |

Descompacte e execute `NIsland.exe`, sem instalação. Se o SmartScreen aparecer: **Mais informações → Executar assim mesmo**.
Passe o mouse na ilha para abrir, clique direito = configurações, **Ctrl+Alt+L** = Central de controle. Idioma: Configurações → Idioma.

## ✨ Recursos
- Música do Spotify, YouTube, navegadores e mais; letras com karaokê (LRCLIB, NetEase) e tradução das linhas.
- Chamadas de apps **e** sites, notificações com cópia de códigos 2FA, chat com IA (grátis sem chave, Claude, OpenAI, Gemini…).
- Timer, Pomodoro, tarefas, calendário, clima, tradutor, área de transferência, notas, mixer por app, 30+ ferramentas.
- 15 estilos incl. **AMOLED**, 7 modos, sons próprios, **modo leve** para PCs fracos (~15–40 MB de RAM).
- Central de controle: índice de saúde, limpeza, 20 otimizações reais do Windows + ajuste por programa (GPU, prioridade de CPU, compatibilidade),
  25 opções de privacidade, registro de atividade (câmera/microfone/localização, permissões de sites, programas executados, USB), 14 reparos. ✨ A IA explica cada opção.

## 🔒 Segurança
Somente configurações e políticas documentadas do Windows; os valores originais são salvos e restaurados pelo mesmo botão.
Direitos de administrador apenas para a ação específica. A limpeza atua só numa lista branca de caches; seus arquivos vão para a lixeira.

## 🖥 Requisitos
Windows 10 (2004+) ou 11, x64/x86, 4 GB de RAM.
