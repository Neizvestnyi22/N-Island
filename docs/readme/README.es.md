**Dynamic Island para Windows — y un Centro de control del portátil fácil para principiantes**

Una isla al estilo iPhone en la parte superior de la pantalla: **música de cualquier app con letras sincronizadas, llamadas, notificaciones, temporizadores y chat con IA** —
además de un **Centro de control del portátil**: limpieza profunda segura, protección antirrastreo, optimización fina de Windows, registro de actividad, energía, red y reparaciones en un clic.
Cada opción tiene etiqueta de seguridad, explicación sencilla y se puede deshacer.

## ⬇️ Descargar
| Archivo | Para quién |
|---|---|
| [**NIsland-win-x64.zip**](https://github.com/Neizvestnyi22/N-Island/releases/latest) | **Recomendado.** Windows 10/11 de 64 bits, todo incluido. |
| [NIsland-win-x86.zip](https://github.com/Neizvestnyi22/N-Island/releases/latest) | Equipos antiguos con Windows 10 de 32 bits. |
| [NIsland-win-x64-lite.exe](https://github.com/Neizvestnyi22/N-Island/releases/latest) | Ligero, requiere [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0). |

Descomprime y ejecuta `NIsland.exe`, sin instalación. Si aparece SmartScreen: **Más información → Ejecutar de todas formas**.
Pasa el ratón por la isla para abrirla, clic derecho = ajustes, **Ctrl+Alt+L** = Centro de control. Idioma: Ajustes → Idioma.

## ✨ Funciones
- Música de Spotify, YouTube, navegadores y más; letras con karaoke (LRCLIB, NetEase) y traducción de líneas.
- Llamadas de apps **y** sitios web, notificaciones con copia de códigos 2FA, chat con IA (gratis sin clave, Claude, OpenAI, Gemini…).
- Temporizador, Pomodoro, tareas, calendario, clima, traductor, portapapeles, notas, mezclador por app, 30+ herramientas.
- 15 estilos incl. **AMOLED**, 7 modos, sonidos propios, **modo ligero** para PCs modestos (~15–40 MB de RAM).
- Centro de control: índice de salud, limpieza profunda, 20 optimizaciones reales de Windows + ajustes por programa (GPU, prioridad de CPU, compatibilidad),
  25 opciones de privacidad, registro de actividad (cámara/micrófono/ubicación, permisos de sitios, programas ejecutados, USB), 14 reparaciones. ✨ La IA explica cada opción.

## 🔒 Seguridad
Solo ajustes y directivas documentadas de Windows; los valores originales se guardan y se restauran con el mismo interruptor.
Permisos de administrador solo para la acción concreta. La limpieza actúa solo en una lista blanca de cachés; tus archivos van a la papelera.

## 🖥 Requisitos
Windows 10 (2004+) u 11, x64/x86, 4 GB de RAM.
