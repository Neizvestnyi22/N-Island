## N-Island 2.4.3 — widgets update in place, a catalog by category

*made in TG [@Ne1zvestny1i](https://t.me/Ne1zvestny1i) & Claude*

Update from the app: **Settings → About → Update** · Обновление прямо из приложения: **Настройки → О программе → Обновить**.

- **/widgets by category** in one message: categories → the category's widgets → back. A chosen widget updates the last one opened from the menu instead of sending a new message every time.
- **New “🧩 All widgets” widget (93 in total):** the whole catalog by category inside one widget — tap a widget and this widget becomes it; “⬅ Back” returns to the catalog.
- **Links between widgets work in place:** buttons that lead to another widget (lyrics, EQ, limits, week, battery…) change this same widget, with “⬅ Back”. Only widgets with their own look (clock, calculator, dice, calendar, breathing, games, countdown, visualizer, load chart, remote, mascot) still come as a new message — they're marked “↗”.
- Live updates, sync with the PC and repeated taps follow the new widget and keep “⬅ Back”.

Виджеты обновляются на месте: меню и каталог по категориям в одном сообщении, переходы между виджетами без новых сообщений, «⬅ Назад».
