## N-Island 2.3.1 — “Answer with widgets” for every command and menu that has a widget

*made in TG [@Ne1zvestny1i](https://t.me/Ne1zvestny1i) & Claude*

Update from the app: **Settings → About → Update** · Обновление прямо из приложения: **Настройки → О программе → Обновить**.

- **Commands:** with “Answer with widgets” on, 64 commands without arguments now answer with a widget (was 39): `/now`, `/vol`, `/note`, `/todo`, `/cliphist`, `/scene`, `/history`, `/speed`, `/health`, `/startup`, `/launch`, `/calc`, `/coin`, `/mem`, `/av`, `/wdstatus`, `/wifihealth`, `/wifiq`, `/channels`, `/router`, `/netusage`, `/in`, `/at`, `/live`, `/bathealth` were added.
- **Bot menus:** 23 menu screens open as widgets — music, sound, output devices, equalizer, mixer, display, power, power plans, network, VPN, timer, tasks, modes, what's loading the PC, windows, presentation, mouse, keyboard, protection, clipboard, history, scheduled commands, scenes. Navigation (main menu, More, settings, permissions, AI, files, tools, System) stays as messages.
- Permissions are respected: if a widget needs a permission that is off (e.g. Power), the bot says where to turn it on. If Telegram doesn't accept a widget, a normal message is sent.
- The self-test checks every one of the 64 commands and 23 menus: a widget with the setting on, the old behaviour with it off.

«Отвечать виджетами» теперь работает для 64 команд и 23 экранов меню; навигация остаётся сообщениями, права соблюдаются.
