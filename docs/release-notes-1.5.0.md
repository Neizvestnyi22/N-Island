### ✨ What's new · Что нового
- 🌍 **9 languages** — Русский, English, Українська, Deutsch, Español, Français, Português, Polski, Türkçe (offline).
- ⚡ **Optimization** — 20 real Windows settings, profiles *Weak laptop / Games / Battery*, per-app GPU, CPU priority and compatibility. Everything reversible.
  **Оптимизация** — 20 настоящих параметров Windows, профили, тонкая настройка программ. Всё с откатом.
- 🕵️ **Activity journal** — who used camera/mic/location and for how long, site permissions in browsers, program launches, notifications, installs, USB drives.
  **Журнал активности** — кто включал камеру и микрофон, что разрешено сайтам, запуски программ, флешки.
- ✨ **AI explanations** next to every option · **ИИ объясняет** каждый пункт простыми словами.
- 🔔 **Real sounds** — chimes, marimba, bell, alarm · **Нормальные звуки** для таймера, напоминаний и уведомлений.
- ⚫ **AMOLED** theme · тема **AMOLED** (чисто чёрная).
- 🐢 **Lite mode** for weak PCs (auto) · **Лёгкий режим** для слабых ПК (включается сам).
- Proper buttons, new About window with update check · нормальные кнопки, новое окно «О программе» с проверкой обновлений.
