# N-Island 2.5.0 — игровые доски и карточки

Обычный релиз визуальной версии, ранее выданной как 2.5.0-preview.5. 29 игр, 15+ новых игр по сравнению с начальной реализацией. Лицевые карты/масти, доски, фишки, игровые поля; ru/en/uk. Имена победителя и проигравшего; исправление повторного открытия приглашения без мёртвого старого поля.

Очистка известных собственных предыдущих ответов после успешной замены; сохраняются пользовательские сообщения и чужие файлы. Безопасный обзор копий приложения по запросу, выбор конкретных файлов/путей и корзина; нет обещания удаления без следов.

Синхронизация громкости, явное снятие ослабления EQ с предупреждением о клиппинге; восстановление ожидания кнопок; устойчивее long polling; обычные файлы отправляются документами в исходном формате без автоматического повтора. Подробности и ограничения в docs/testing/2.5.0-preview.4.md и 2.5.0-preview.5.md.

**Что проверено:** Linux cross-build/publish; 4370 игровых утверждений; 174 состояния (29 игр × 3 языка × 2 стороны), 58 strict sandbox (29 × светлая/тёмная), 29 Chromium-макетов 360 px без горизонтального переполнения, 11 запросов виджетов; предыдущие проверки 1052 widget, 28 transport/files/EQ, 21 reply, 10 fake-COM audio. HTML игры 9843 UTF-8 / 4022 zlib байта. PE/ZIP/SHA256 проверяются при упаковке.

**Что НЕ проверено:** реальный запуск новой визуальной версии и штатная замена/миграция через updater на Windows, два живых Telegram-игрока, качество звука/нагрузка реального ноутбука. Пользователь подтвердил запуск и нормальную работу предыдущей preview.4 после полного извлечения ZIP и разрешил выпуск завершённой визуальной версии. Это не свидетельство остальных тестов. Обычный релиз здесь означает канал GitHub/latest, а не отсутствие указанных ограничений.

Шахматы без часов и полной турнирной процедуры ничьих. Тяжёлый персонаж без новой тайм-аут-обёртки из-за лимита Telegram. Подъём EQ может клиппировать; снизьте громкость перед включением «Убрать ослабление».

Сборки как раньше: win-x64 ZIP и win-x86 ZIP self-contained; x64-lite EXE требует .NET 8 Desktop Runtime x64. Контрольные суммы в SHA256SUMS.txt. EXE не подписан: защиту не отключать. Для ручной установки ZIP сначала «Извлечь всё», не запускать из окна архива. При обновлении сохраните резервную копию данных; при неопределённой отправке файла проверьте чат перед повтором.

Удаление тестовой portable: выйти, проверить PID/путь выбранной копии, после проверки личных файлов перенести именно её папку в корзину. data-preview удалять отдельно по своему выбору. Общую %APPDATA%\NIsland не удалять, если она нужна рабочей версии. Журналы ОС/чужие данные не трогать.
